# TalentForge Institute

Production-grade bilingual marketing website for TalentForge Institute — GenAI Full-Stack Bootcamp and corporate AI training for Indonesia and Southeast Asia.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Custom SVG illustrations

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
```

The app binds to `0.0.0.0:$PORT` in production via Next.js (`npm start`).

## Pages

- `/` — Homepage
- `/programs` — Bootcamp & program catalog
- `/corporate` — Corporate training
- `/about` — Founder & mission
- `/faq` — Bilingual FAQ
- `/contact` — Contact & inquiry form

Language toggle (EN / ID) persists in `localStorage`.
